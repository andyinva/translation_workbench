translation_workbench, English literal translation
Printed from docs/translit_candidates.md (2026-10-25)
==============================================================================

HOW TO USE
  Mark each word: YES (transliterate), NO (translate into English), or
  LATER (decide after the trial). Write a note if you wish.

THE FIVE TESTS (a word qualifies with two)
  1 English has no faithful word, or the usual word misleads
  2 Closed set (feast, offering, object, garment, measure)
  3 The Hebrew links passages that English separates
  4 Identity or meaning is uncertain
  5 The text plays on or explains the word

STRENGTH: strong, maybe, rule (a measure, already decided), familiar
  (English already has the form), hold (frequent word, decide separately).
  Uses = Old Testament occurrences.

DECIDED: yovel (H3104) in all 27 uses.

SIZE OF THE TRIAL
  Set A (strong only): 30 words, 790 uses, 1 word in 380.
  Set B (A + familiar + measures): 55 words, 1 word in 220.
  Set C (B + maybe): 86 words, 1 word in 130.
  Suggested trial chapters: Lev 25, Josh 6, Ruth 4, Eccl 1, Exod 28.
